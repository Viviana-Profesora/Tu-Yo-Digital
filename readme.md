# Tu Yo Digital

**Tu Yo Digital** es una página web creada como proyecto de aprendizaje de HTML y CSS.

El sitio presenta servicios de clases particulares de informática y herramientas digitales para el análisis y organización de datos.

## Contenido

La página incluye:

* Presentación del proyecto
* Clases particulares de informática
* Planillas para análisis de datos
* Carrito de compras
* Formulario de contacto

## Tecnologías utilizadas

* HTML5
* CSS
* Google Fonts
* Flexbox
* CSS Grid
* Media Queries

## Objetivo

El objetivo del proyecto es aplicar los conocimientos aprendidos sobre estructura HTML, estilos CSS, diseño responsive, navegación y formularios.
